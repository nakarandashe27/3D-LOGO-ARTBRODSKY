# 3D-эмблема ÁРТ.БРÓДСКИЙ · интерактивная 3D-страница

**Открыть:** https://nakarandashe27.github.io/3D-LOGO-ARTBRODSKY/ · без панели: https://nakarandashe27.github.io/3D-LOGO-ARTBRODSKY/#ui=0

Онлайн-школа ÁРТ.БРÓДСКИЙ — знак «а» в виде настоящего изделия: металл, горячая эмаль
фирменного градиента, купол эпоксидной смолы, на обороте — гравировка шрифтом Unbounded
и сапфир. Эмблему можно крутить, переворачивать, разбирать по слоям и настраивать.
Интерфейс оформлен по брендбуку и сайту [artbrodsky.ru](https://artbrodsky.ru/):
чёрный #161010, градиент #F74C2E → #4D61F4, Unbounded + Inter Tight, кнопки-«пилюли».

Сделано на [Three.js](https://threejs.org) + [Vite](https://vite.dev). Геометрия строится в
браузере из векторного логотипа, окружение студии процедурное; собранная страница не
обращается к внешним CDN и работает офлайн.

## Версии логотипа

Переключаются в нижней панели или клавишами **1–6** (удобно на презентации без панели).

| # | Версия | Что это | Источник |
|---|---|---|---|
| 1 | Знак | знак «а» без дескриптора | брендбук, стр. 1 |
| 2 | Круг | белый знак на градиентном круге | иконка сайта artbrodsky.ru |
| 3 | Плитка | знак на скруглённом квадрате | плитки брендбука, стр. 1–4 |
| 4 | Подпись снизу | знак + «арт.бродский / студенты» | брендбук, стр. 3 |
| 5 | Подпись сбоку | горизонтальная версия | брендбук, стр. 5 |
| 6 | По центру | надпись поверх знака | брендбук, стр. 7 (собрана из векторов стр. 3) |

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статика в dist/
npm run preview    # собранная версия
```

## Деплой

Каждый push в `main` публикует сайт на GitHub Pages ([workflow](.github/workflows/deploy.yml)).
Один раз в настройках репозитория: *Settings → Pages → Source: GitHub Actions*.
`dist/` можно выложить и на Netlify Drop / Vercel / любой статический хостинг.

## Как показать на презентации

- Открыть ссылку и нажать **P** — полный экран без панели (**H** — панель, **Esc** — выход).
  Сразу без панели: добавить к адресу `#ui=0`.
- PowerPoint: надстройка *Web Viewer* (живая страница) или Экспорт → «3D · GLB» →
  *Вставка → 3D-модели* (вращается прямо на слайде, без интернета).
- Подстраховка: Экспорт → «Видео 360°» или «PNG» с прозрачным фоном.

## Настройка под бренд

Всё брендовое — в [`src/brand.config.js`](src/brand.config.js) и файлах `src/assets/`:
тексты оборота, палитра эмали (первой идёт фирменный градиент), версии логотипа и их роли
цветов. Цвета в SVG: `#f74c2e` — знак (эмаль), `#161010` — дескриптор (чернение; на чёрном
никеле — белая эмаль), `#ffffff` — «бумага» (прорезь до металла).

Оформление интерфейса — [`src/style.css`](src/style.css): темы «Чёрный», «Графит», «Белый»
(как светлые секции сайта) и «Градиент» (фон из брендбука). Свет «Бренд» — красный и синий
стрипбоксы, металл отражает цвета градиента.

## Логотип

Логотип и название ÁРТ.БРÓДСКИЙ принадлежат правообладателю. Источник векторов — брендбук
«студенты» (PDF), иконка «Круг» — по иконке сайта artbrodsky.ru, картинка градиента —
из брендбука. Лицензия на код не распространяется на логотип.
